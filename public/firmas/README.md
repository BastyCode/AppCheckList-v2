# Firmas de Técnicos

Esta carpeta contiene las imágenes de firmas de los técnicos.

## Archivos:
- `christian-torrens.png` - Firma de Christian Torrens
- `jerson-armijo.png` - Firma de Jerson Armijo
- `bastian-jimenez.png` - Firma de Bastian Jimenez

## Instrucciones:
1. Reemplaza los archivos placeholder con las imágenes reales de las firmas
2. Usa formato PNG o JPG
3. Mantén los mismos nombres de archivo
4. Tamaño recomendado: 300x100 px o similar (horizontal)
5. Fondo transparente preferible (PNG)

## Importante:
- Esta carpeta se copia automáticamente al build
- Las imágenes funcionarán tanto en desarrollo como en producción
- No cambies los nombres de archivo sin actualizar el código
